# General Plan v3: 26.09 → 29.09.2026

> Продолжение [GEN_V2_PLAN](GEN_V2_PLAN.md) (закрыт). Заморозка кода — 29.09 днём, сдача — 30.09.

Связанные документы: [INDEX](INDEX.md) · [HANDOFF](HANDOFF.md) · [judging-criteria](research/judging-criteria.md) · [ADR](adr/README.md)

## Откуда итерация
- **GEN_V2 закрыт.** Шлифовка, подтверждение ремонта, телефон для мастера, кабинет района, импорт и геокодер, совет дома. Коллега дописал деплой, реестр PDF, фото-пруф, фильтры УК, календарь РФ, экспорт для сдачи.
- **Брейншторм 26.09** (скил brainstorming, команда): «имбовые» бизнес-фичи и UX, в том числе для незрячих и пожилых.
- **Замечания Максима после проверки в MAX:**
  - в мини-приложении не выбрать дом по геолокации;
  - у бота мало функций;
  - кнопки «уезжают»: каждое нажатие присылает новое сообщение.
- **Идея Германа:** карта домов для УК и района, точка тем больше, чем больше проблем.

Критерии, на которые бьём ([judging-criteria](research/judging-criteria.md)):
- масштабирование 35% — карта, рейтинг;
- UX 20% — бот 2.0, голос, доступность;
- ценность 25% — обращение с подписями, рейтинг;
- бонус MAX — транскрипция голосовых, `openMaxLink`, `request_contact`.
