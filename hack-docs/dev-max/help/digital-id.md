# Цифровой ID

> Подключение к сервису Цифрового ID на платформе MAX для партнёров доступно только для юрлиц и ИП (резидентов РФ). Для самозанятых Цифровой ID недоступен

## Для чего нужен Цифровой ID бизнесу?

Если у вашего магазина или торговой точки подключён Цифровой ID в MAX, покупатели могут подтвердить совершеннолетие, а также льготные статусы студента, человека с инвалидностью, многодетного и пенсионера без бумажных документов: с помощью QR-кода (Android и iOS) или NFC (только Android) в мессенджере MAX

## Как покупателям подтвердить совершеннолетие и льготные статусы через Цифровой ID?

У покупателей должен быть создан Цифровой ID в мессенджере MAX

После создания Цифрового ID в мессенджере MAX у пользователей появляется QR-код, который можно предъявить на кассе вместо паспорта и других бумажных документов для подтверждения совершеннолетия и льготных статусов. Функциональность доступна на устройствах с iOS и Android. Вместо QR-кода покупатели могут также использовать NFC – доступно только на устройствах с Android

Покупатели могут предъявить Цифровой ID с помощью QR-кода или NFC кассиру или через кассу самообслуживания. Идентификатор динамический и обновляется каждые 25 секунд

## Что такое цифровое заселение через MAX и как отелям его подключить?

С помощью Цифрового ID в MAX отели могут заселять гостей без бумажных документов, быстрее вносить данные гостя и снижать количество ошибок при ручном заполнении

Цифровое заселение через MAX доступно **без регистрации на платформе MAX для партнёров**. В материалах [по ссылке](https://cloud.mail.ru/public/Hr3H/URzZ6R2sV) собраны инструкции для отелей и поставщиков отельных систем по внедрению заселения с помощью Цифрового ID в MAX, а также описание сценария работы, маркетинговые материалы и нормативные документы

## Что нужно для подключения Цифрового ID?

> Подключение к сервису Цифрового ID на платформе MAX для партнёров доступно только для юрлиц и ИП (резидентов РФ). Для самозанятых Цифровой ID недоступен

Перед подключением необходимо [создать и верифицировать профиль](../docs/maxbusiness/connection.md#Этап%202.%20Создание%20профиля%20организации,%20ИП%20или%20самозанятого) организации или ИП на платформе MAX для партнёров. Также проверьте, что у вас есть профиль в мессенджере MAX, зарегистрированный на номер телефона, с которым вы входите на платформу

## Как подключить Цифровой ID?

> Подключение к сервису Цифрового ID на платформе MAX для партнёров доступно только для юрлиц и ИП (резидентов РФ). Для самозанятых Цифровой ID недоступен

1. Перейдите в профиль вашей организации или ИП на [платформе](https://business.max.ru/self)
2. В разделе **Цифровой ID** выберите **Создать**
3. Нажмите **Получить токен**
4. Дождитесь генерации токена и скопируйте его
5. Нажмите **Инструкция для подключения** — вы перейдёте к описанию API Цифрового ID MAX и сможете настроить взаимодействие с кассами ваших магазинов или торговых точек. Используйте полученный токен для аутентификации при отправке запросов через API Цифрового ID MAX

## Как обновить токен Цифрового ID?

> - Срок жизни токена Цифрового ID — 1 год
> - Обратите внимание: после обновления токена все магазины и торговые точки, подключённые к Цифровому ID, будут отключены — вам потребуется настроить взаимодействие по API заново, с новым токеном
> - Если вы хотите обновить токен до окончания его срока жизни, рекомендуем это делать только в **исключительных** случаях, например, если вы подозреваете, что токен попал в руки мошенников

1. Перейдите в профиль вашей организации или ИП на [платформе](https://business.max.ru/self)
2. В разделе **Цифровой ID** нажмите **Настроить**
3. В правом верхнем углу нажмите на три точки → **Обновить токен**
4. Отправьте заявку на почту с экрана
5. Дождитесь уведомления о смене токена, затем на платформе в разделе **Цифровой ID** нажмите **Настроить** и скопируйте новый токен
6. Перейдите к описанию интеграции по API Цифрового ID MAX, нажав **Инструкция для подключения**, и повторно настройте взаимодействие с вашими магазинами и торговыми точками
