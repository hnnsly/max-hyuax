# Регистрация на платформе

## Кто может подключиться к платформе MAX для партнёров?

Подключение к платформе MAX для партнёров и её сервисам — чат-ботам, мини-приложениям, каналам — доступно для юрлиц, ИП и самозанятых, которые являются резидентами РФ. Подключение к сервису Цифрового ID доступно только для юрлиц и ИП (резидентов РФ)

Физические лица и нерезиденты пока не смогут пройти верификацию на платформе

## В чём отличия при работе с платформой для самозанятых и организаций, ИП?

| Возможности при работе с платформой | Самозанятые | Организации и ИП |
| --- | --- | --- |
| Количество ботов, которое можно создать на платформе | 2 | 5 |
| Шаблон, по которому генерируется никнейм бота | `se(orgid)_bot`<br>, где `(orgid)` — идентификатор профиля [на платформе](https://business.max.ru/self) | `idИНН_bot`<br>, где ИНН — номер организации или ИП |
| Шаблон, по которому генерируется никнейм канала | `se(orgid)_biz`<br>, где `(orgid)` — идентификатор профиля [на платформе](https://business.max.ru/self) | • `idИНН_biz` — первый канал <br>• `idИНН_biz2`, `idИНН_biz3`... `idИНН_biz{номер канала}` — последующие, <br>где `ИНН` — номер вашей организации или ИП |
| Подключение сервиса Цифрового ID | Недоступно | Доступно |
| Способ подтверждения профиля на платформе | Только Госуслуги | Госуслуги или банковские сервисы (T-Business ID, Alfa ID — подтверждение через банки пока доступно только в веб-версии платформы) |

## Какой номер телефона указать при регистрации на платформе для партнёров?

Регистрируйтесь с рабочим номером телефона ответственного представителя

> Номер должен быть актуальным и находиться у вас в постоянном доступе, так как на него будут приходить коды подтверждения и важные уведомления

Указанному при регистрации номеру телефона будет соответствовать один профиль организации, ИП или самозанятого и привязанные к нему сервисы: чат-боты, мини-приложения, каналы, сервисы партнёров и Цифровой ID

Если у вас есть канал с меткой A+ на другой платформе: ВКонтакте, Дзен, Одноклассники, Telegram — вы можете создать в MAX канал с таким же названием и ником. В этом случае при регистрации используйте номер телефона, на который создан канал на другой платформе

## Какие данные указывать при регистрации аккаунта в мессенджере MAX?

При регистрации в поле для имени и фамилии указывайте имя и фамилию ответственного представителя, а не название организации или вашего бизнеса. Иначе данные такого аккаунта могут быть распознаны как подозрительные — это повлечёт за собой блокировку
