# Работа в мини-приложении «MAX для бизнеса» и чат-боте «MAX для бизнеса»

Для удобства прямо в мессенджере МАКС вы можете пройти основные сценарии работы с сервисами для бизнеса:

- Верификацию организации, ИП или самозанятого
- Создание и редактирование чат-бота
- Получение токена бота
- Создание канала или получение метки А+
- Выбор партнёра для интеграции

Для этого используйте [мини-приложение «MAX для бизнеса»](https://max.ru/business_bot?startapp) или [бот «MAX для бизнеса»](https://max.ru/business_bot)

![Выбор типа профиля](https://dev.max.ru/assets/miniapp.png "Выбор типа профиля")

## Как воспользоваться мини-приложением «MAX для бизнеса»?

[Мини-приложение «MAX для бизнеса»](https://max.ru/business_bot?startapp) доступно в мессенджере МАКС. Вы можете открыть его двумя способами:

- Прямой вход по ссылке [`https://max.ru/business_bot?startapp`](https://max.ru/business_bot?startapp)
- Через бот «MAX для бизнеса», который можно запустить в разделе мессенджера **Настройки** → **MAX для бизнеса** или по ссылке [`https://max.ru/business_bot`](https://max.ru/business_bot).  
   После открытия бота нажмите **Начать** — далее с помощью кнопки **Старт** вы можете сразу приступить к работе в мини-приложении или воспользоваться переходом в главное меню и выбрать в списке команд подходящую, например **Создать канал или получить А+**. В каждом из вариантов вы продолжите работу с платформой в мини-приложении

## Как пройти верификацию в мини-приложении «MAX для бизнеса»?

> Пройти верификацию в мини-приложении «MAX для бизнеса» пока можно только через Госуслуги

1. Откройте мини-приложение по ссылке [`https://max.ru/business_bot?startapp`](https://max.ru/business_bot?startapp) или через раздел мессенджера **Настройки** → **MAX для бизнеса** → **Начать** → **Старт**
2. Выберите тип профиля организации
3. Выберите верификацию через Госуслуги и подтвердите организацию, ИП или статус самозанятого

После прохождения верификации в мини-приложении откроется главный экран платформы MAX для партнёров с выбором сервиса для интеграции

## Как пройти верификацию с помощью бота «MAX для бизнеса»?

> Пройти верификацию в мини-приложении «MAX для бизнеса» пока можно только через Госуслуги

1. В мессенджере МАКС откройте [бот «MAX для бизнеса»](https://max.ru/business_bot) и нажмите **Начать**
2. Выберите **Создать канал или получить А+** или **Создать чат-бот** — в зависимости от того, какой сервис собираетесь подключить на платформе.  
   В результате вы увидите сообщение, что создать канал или чат-бот может только верифицированный пользователь
3. Нажмите **Пройти верификацию**.  
   В результате откроется мини-приложение «MAX для бизнеса»
4. Выберите нужный тип профиля организации
5. Выберите верификацию через Госуслуги и подтвердите организацию, ИП или статус самозанятого

После прохождения верификации от бота «MAX для бизнеса» поступит сообщение, что теперь вы можете создать канал или чат-бот

## Как открыть мини-приложение «MAX для бизнеса» из бота «MAX для бизнеса»?

В мессенджере МАКС запустите [бот «MAX для бизнеса»](https://max.ru/business_bot), в нижнем левом углу нажмите **Начать** → **Старт** или сразу **Старт**, если уже работали с ботом.  
 В результате вы увидите главный экран мини-приложения «MAX для бизнеса» со списком сервисов для интеграции

## Как узнать токен через бот «MAX для бизнеса»?

> Получить токен в боте «MAX для бизнеса» можно, если вы прошли верификацию профиля и модерацию бота через мини-приложение

Когда ваш чат-бот пройдёт модерацию, вы увидите сообщение со списком команд от [бота «MAX для бизнеса»](https://max.ru/business_bot). Выберите **Получить токен** — откроется окно мини-приложения «MAX для бизнеса», в котором можно скопировать токен

Если вы верифицировали профиль в веб-версии платформы MAX для партнёров, вам будет предложена ссылка для перехода и просмотра токена в веб-версии

## Как создать чат-бот через бот «MAX для бизнеса»?

1. В мессенджере МАКС откройте [бот «MAX для бизнеса»](https://max.ru/business_bot)
2. В нижнем левом углу нажмите **Начать** → **Старт** или сразу **Старт**, если уже работали с ботом
3. Если вы ещё не прошли верифкацию, пройдите её — подробнее об этом во втором вопросе текущего раздела. Если верификация пройдена, в боте вы увидите список команд — выберите **Создать чат-бот**.  
   В результате откроется окно создания чат-бота — следуйте [инструкции](../docs/chatbots/bots-create/create.md)

## Как создать канал через бот «MAX для бизнеса»?

1. В мессенджере МАКС откройте [бот «MAX для бизнеса»](https://max.ru/business_bot)
2. В нижнем левом углу нажмите **Начать** → **Старт** или сразу **Старт**, если уже работали с ботом
3. Выберите **Создать канал или получить А+**
4. Если вы ещё не прошли верифкацию, пройдите её — подробнее об этом во втором вопросе текущего раздела. Если верификация пройдена, в боте вы увидите список команд — выберите **Создать канал**.  
   В результате откроется чат-бот для создания канала — следуйте инструкции на экране

## Как получить метку А+ для канала через бот «MAX для бизнеса»?

1. В мессенджере МАКС откройте [бот «MAX для бизнеса»](https://max.ru/business_bot) и выберите **Создать канал или получить А+**
2. Если вы ещё не прошли верифкацию, пройдите её — подробнее об этом о втором вопросе текущего раздела. Если верификация пройдена, в боте вы увидите список команд — выберите **Получить метку А+**.  
   В результате откроется чат-бот для получения метки А+ — следуйте инструкции на экране
