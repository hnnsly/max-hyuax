# Управление ботом на платформе

Помимо использования веб-версии [платформы MAX для партнёров](https://business.max.ru/self), управлять чат-ботом можно с помощью [мини-приложения «MAX для бизнеса»](https://max.ru/business_bot?startapp)

Шаги управления чат-ботом в веб-версии и мини-приложении «MAX для бизнеса» совпадают. Подробнее о работе с чат-ботом с помощью мини-приложения или бота читайте в [разделе «FAQ»](../../../help/miniapp-main.md)

## Настройка приватности бота и добавление мини-приложения

После [модерации](create.md#Модерация%20бота) бота вам станут доступны настройки. Чтобы посмотреть их, перейдите в раздел платформы **Чат-боты**, выберите необходимого бота и нажмите **⋮** → **Настройки**

- **Чат-бот**:
  - **Токен доступа** — вы можете скопировать токен бота для его дальнейшей настройки, а также обновить его
  - **Приватность** — вы можете разрешить или запретить добавление бота в групповые чаты. По умолчанию стоит запрет
- **Мини-приложение**:
  - **Введите ссылку** — вы можете указать ссылку на мини-приложение для его привязки к боту
  - **Выберите кнопку открытия мини-приложения** — вы можете выбрать один из вариантов: **Открыть**, **Старт**, **Играть** или без названия (по умолчанию). Подробнее – [в разделе про мини-приложения](../../webapps/introduction.md#Как%20добавить%20приложение%20в%20MAX)

## Редактирование бота

> - Поменять данные бота можно только на платформе MAX для партнёров (отредактировать их в мессенджере MAX не получится) и только после прохождения [модерации](create.md#Модерация%20бота). Если вы не хотите ждать её окончания, удалите бота и создайте нового с необходимыми данными
> - Изменить можно все данные бота, кроме ника

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и нажмите **→**
3. Внесите изменения в разделе **Основная информация** и нажмите **Сохранить** — бот будет отправлен на повторную [модерацию](create.md#Статусы%20модерации)

![](https://dev.max.ru/assets/chat_bots/bot_select.png)

![](https://dev.max.ru/assets/chat_bots/bot_info.png)

*Основная информация*

Пока идёт проверка, бот остаётся в прежнем виде для конечных пользователей.
Изменения применяются после успешной модерации

## Получение токена бота

После успешной проверки чат-бота сформируется **токен** — уникальный идентификатор бота, с помощью которого бот будет взаимодействовать с [API MAX](../../../docs-api/index.md)

Чтобы скопировать токен бота:

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и нажмите **⋮** → **Настройки**
3. Справа от поля с токеном нажмите на значок копирования

![](https://dev.max.ru/assets/chat_bots/bot_options.png)

![](https://dev.max.ru/assets/chat_bots/integration_token.png)

*Получение токена бота*

Наличие токена означает, что бот зарегистрирован на платформе MAX для партнёров

> **Пример токена**  
>  
> `AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`

Так как токен — это прямой доступ к боту, не рекомендуется хранить его в открытых источниках или передавать посторонним: они смогут завладеть ботом и управлять им от вашего имени. Если вы опасаетесь, что токен скомпрометирован, [обновите его](#Обновление%20токена%20бота)

Подробнее о том, как получить токен чат-бота с помощью [мини-приложения «MAX для бизнеса»](https://max.ru/business_bot?startapp) или [бота «MAX для бизнеса»](https://max.ru/business_bot), читайте в [разделе «FAQ»](../../../help/miniapp-main.md)

## Обновление токена бота

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и нажмите **⋮** → **Настройки**
3. Справа от поля с токеном нажмите на значок обновления

## Удаление бота

ℹ️ После удаления ваши клиенты не смогут пользоваться ботом. Удалённого бота нельзя восстановить

Чтобы удалить бота:

1. Перейдите на [платформу MAX для партнёров](https://business.max.ru/self) в раздел **Чат-боты**
2. Выберите необходимого бота и удалите его одним из способов:
   - Либо нажмите **⋮** → **Удалить**
   - Либо нажмите **→** и в разделе **Основная информация** выберите **Удалить чат-бот**
