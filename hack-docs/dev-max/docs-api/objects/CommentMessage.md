# CommentMessage

Комментарий в чате. Возвращается в ответ на запросы группы [`/comments`](../methods/GET/messages/-messageId-/comments/index.md). В отличие от обычного сообщения в чате или канале не содержит вложений `attachments` и не поддерживает пересылку комментариев (поле `link.type = forward`)

- **`sender`** — object [User](User.md) · optional

  Пользователь, отправивший комментарий. Может быть `null`, если сообщение было опубликовано от имени канала

- **`recipient`** — object Recipient

  Получатель сообщения: для комментариев — канал

  - **`chat_id`** — integer &lt;int64&gt; · Nullable

    ID чата или канала. Как получить ID — в [разделе «Получение chat_id»](../index.md#Получение%20chat_id)

  - **`chat_type`** — enum ChatType

    Возможные значения в enum: `"chat"` `"channel"` `"dialog"`

    Тип чата:
    - `chat` — групповой чат
    - `channel` — канал или комментарий к посту (для вызовов методов группы `/comments`)
    - `dialog` — диалог

  - **`user_id`** — integer &lt;int64&gt; · Nullable

    ID получателя сообщения в диалоге (пользователя или бота). Если сообщение отправлено в групповой чат или канал, то параметр отсутствует

  - **`post_id`** — string · Nullable

    Идентификатор поста в канале, к которому оставлен комментарий

- **`timestamp`** — integer &lt;int64&gt;

  Время создания сообщения в формате Unix timestamp в миллисекундах

- **`link`** — object CommentLinkedMessage · Nullable · optional

  Комментарий, на который получен ответ

  - **`type`** — enum MessageLinkType

    Возможные значения в enum: `"forward"` `"reply"`

    Тип связанного сообщения:
    - `"reply"` — ответ на сообщение или комментарий в чате или канале
    - `"forward"` — пересланное сообщение в чате или канале

    **Для комментариев поддерживается только тип `reply`**

  - **`sender`** — object [User](User.md) · optional

    Пользователь или бот, отправивший комментарий

  - **`chat_id`** — integer &lt;int64&gt; · optional

    Чат или канал, в котором сообщение было изначально опубликовано. Только для пересланных сообщений с `type = forward`. Как получить ID — в [разделе «Получение chat_id»](../index.md#Получение%20chat_id)

  - **`message`** — object CommentMessageBody

    Информация о комментарии

    - **`mid`** — string

      Уникальный ID комментария

    - **`seq`** — integer &lt;int64&gt;

      Порядковый номер расположения комментария в посте

    - **`text`** — string · Nullable

      Текст комментария

    - **`markup`** — MarkupElement[] · Nullable · optional

      Разметка текста комментария. Подробнее — в разделе [Форматирование](../index.md#Форматирование%20текста%20в%20сообщениях)

      **Обратите внимание**: в тексте комментариев не поддерживаются гиперссылки и упоминание пользователя

      - Вариант `type = "strong"` — StrongMarkup

        Представляет **жирный** текст

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

      - Вариант `type = "emphasized"` — EmphasizedMarkup

        Представляет *курсив*

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

      - Вариант `type = "monospaced"` — MonospacedMarkup

        Представляет `моноширинный` или блок ```код``` в тексте

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

      - Вариант `type = "link"` — LinkMarkup

        Представляет ссылку в тексте

        **Обратите внимание**: в тексте комментариев гиперссылки не поддерживаются

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

        - **`url`** — string

          от `1` до `2048` символов

          URL ссылки

      - Вариант `type = "strikethrough"` — StrikethroughMarkup

        Представляет ~зачёкрнутый~ текст

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

      - Вариант `type = "underline"` — UnderlineMarkup

        Представляет <ins>подчёркнутый</ins> текст

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

      - Вариант `type = "user_mention"` — UserMentionMarkup

        Представляет упоминание пользователя в тексте. Упоминание может быть как по имени пользователя, так и по ID, если у пользователя нет имени

        **Обратите внимание**: в тексте комментариев упоминание пользователя не поддерживаются

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

        - **`user_link`** — string · Nullable · optional

          `@username` упомянутого пользователя

        - **`user_id`** — integer &lt;int64&gt; · Nullable · optional

          ID упомянутого пользователя без имени

      - Вариант `type = "heading"` — HeadingMarkup

        Представляет заголовок

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

      - Вариант `type = "highlighted"` — HighlightedMarkup

        Представляет выделенный текст

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах

      - Вариант `type = "quote"` — QuoteMarkup

        Представляет цитату

        - **`from`** — integer &lt;int32&gt;

          Индекс начала элемента разметки в тексте. Нумерация с нуля

        - **`length`** — integer &lt;int32&gt;

          Длина элемента разметки в символах
