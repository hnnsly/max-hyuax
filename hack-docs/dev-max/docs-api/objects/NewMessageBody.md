# NewMessageBody

Объект используется при отправке нового сообщения в чат или канал[`POST /messages`](../methods/POST/messages/index.md), редактировании существующего сообщения или поста [`PUT /messages`](../methods/PUT/messages/index.md), а также callback-отправке сообщения пользователю при нажатии им кнопки в чате или канале [`POST /answers`](../methods/POST/answers.md)

Параметры объекта содержат: текст и способ его форматирования, вложения, ссылку на связанное сообщение (ответ или пересылка), настройку PUSH-уведомлений для участников чата

- **`text`** — string · Nullable

  до `4000` символов

- **`attachments`** — AttachmentRequest[] · Nullable

  Вложения сообщения. Если поле пустое или равно `null`, изменений не произойдет. Если массив пуст, все вложения будут удалены

  - Вариант `type = "image"` — PhotoAttachmentRequest

    - **`payload`** — object PhotoAttachmentRequestPayload

      Данные для прикрепления изображения (все поля являются взаимоисключающими). Вместе с изображениями можно прикрепить видеофайлы (`type: video`) и одно вложение с кнопками (`type: inline_keyboard`). Общее количество вложений не должно превышать общее ограничение — 12. Подробнее — [в примерах](../index.md#Примеры%20с%20видео,%20изображением,%20файлом)

      - **`url`** — string · Nullable · optional

        от `1` символа

        Любой внешний URL изображения, которое вы хотите прикрепить

      - **`token`** — string · Nullable · optional

        Токен существующего вложения

      - **`photos`** — object · Nullable · optional

        Токены, полученные после загрузки изображений

  - Вариант `type = "video"` — VideoAttachmentRequest

    Данные для прикрепления видео к сообщению. Вместе с видео можно прикрепить изображения (`type: image`) и одно вложение с кнопками (`type: inline_keyboard`). Общее количество вложений не должно превышать общее ограничение — 12. Подробнее — [в примерах](../index.md#Примеры%20с%20видео,%20изображением,%20файлом)

    - **`payload`** — object UploadedInfo

      Данные, которые вы получили в ответ на запрос [POST /uploads](../methods/POST/uploads.md). Можно передавать после того, как вы загрузили аудио, видео или файл и получили в ответ от сервера `retval`. Подробнее — в описании [POST /uploads](../methods/POST/uploads.md)

      - **`token`** — string · optional

        Токен вложения — уникальный ID загруженного медиа: изображения, аудио, видео или файла. Возвращается в ответ на вызов [POST /uploads](../methods/POST/uploads.md)

  - Вариант `type = "audio"` — AudioAttachmentRequest

    Запрос на прикрепление аудио к сообщению. Должен быть единственным вложением в сообщении

    - **`payload`** — object UploadedInfo

      Данные, которые вы получили в ответ на запрос [POST /uploads](../methods/POST/uploads.md). Можно передавать после того, как вы загрузили аудио, видео или файл и получили в ответ от сервера `retval`. Подробнее — в описании [POST /uploads](../methods/POST/uploads.md)

      - **`token`** — string · optional

        Токен вложения — уникальный ID загруженного медиа: изображения, аудио, видео или файла. Возвращается в ответ на вызов [POST /uploads](../methods/POST/uploads.md)

  - Вариант `type = "file"` — FileAttachmentRequest

    Данные для прикрепления файла к сообщению, которые вы получили в ответ на запрос [POST /uploads](../methods/POST/uploads.md). Файл можно отправить только в комбинации с вложением с кнопками — отправка совместно с изображением или видео не поддерживается. При этом к сообщению можно прикрепить только один файл и одно вложение с кнопками. Подробнее — в описании [POST /uploads](../methods/POST/uploads.md)

    - **`payload`** — object UploadedInfo

      Данные для прикрепления файла к сообщению, которые вы получили в ответ на запрос [POST /uploads](../methods/POST/uploads.md). К сообщению можно прикрепить только один файл вместе с одним вложением с кнопками. Отправка файла совместно с другими вложениями не поддерживается

      - **`token`** — string · optional

        Токен вложения — уникальный ID загруженного медиа: изображения, аудио, видео или файла. Возвращается в ответ на вызов [POST /uploads](../methods/POST/uploads.md)

  - Вариант `type = "sticker"` — StickerAttachmentRequest

    Запрос на прикрепление стикера. ДОЛЖЕН быть единственным вложением в сообщении

    - **`payload`** — object StickerAttachmentRequestPayload

      - **`code`** — string

        Код стикера

  - Вариант `type = "contact"` — ContactAttachmentRequest

    Запрос на прикрепление карточки контакта к сообщению. Должен быть единственным вложением в сообщении

    - **`payload`** — object ContactAttachmentRequestPayload

      Данные для прикрепления карточки контакта к сообщению. К сообщению можно прикрепить только один контакт. Совместно с ним можно прикрепить дополнительно одно вложение с кнопками (`type: inline_keyboard`). Передача других типов вложений совместно с контактом не поддерживается

      - **`name`** — string · Nullable

        Имя контакта

      - **`contact_id`** — integer &lt;int64&gt; · Nullable · optional

        ID контакта, если он зарегистирован в MAX

      - **`vcf_info`** — string · Nullable · optional

        Полная информация о контакте в формате VCF

      - **`vcf_phone`** — string · Nullable · optional

        Телефон контакта в формате VCF

  - Вариант `type = "inline_keyboard"` — InlineKeyboardAttachmentRequest

    Запрос на прикрепление клавиатуры к сообщению

    - **`payload`** — object InlineKeyboardAttachmentRequestPayload

      Данные для прикрепления кнопок к сообщению
      Ограничения:
      - Максимальное количество кнопок в ряду — 7
      - Максимальное количество строк с кнопками — 30
      - Если в ряду кнопки с типами: `link`, `open_app`, `request_geo_location`, `request_contact`, то максимальное количество кнопок в ряду — 3

      - **`buttons`** — Button[][]

        от `1` символа

        Двумерный массив кнопок. Подробнее о типах кнопок и клавиатуре в ботах — [в разделе «Клавиатура для чат-бота»](../index.md#Клавиатура%20для%20чат-бота)

        - Вариант `type = "callback"` — CallbackButton

          После нажатия на такую кнопку клиент отправляет на сервер полезную нагрузку, которая содержит

          - **`text`** — string

            от `1` до `128` символов

            Видимый текст кнопки. Чтобы он отображался полностью, рекомендуем не превышать заданное количество символов в зависимости от размещения текста: `20` символов — при 1 кнопке в ряду, `10` — при 2, `5` — при 3, `3` — при 4

          - **`payload`** — string

            до `1024` символов

            Токен кнопки

        - Вариант `type = "link"` — LinkButton

          После нажатия на такую кнопку пользователь переходит по ссылке, которую она содержит

          - **`text`** — string

            от `1` до `128` символов

            Видимый текст кнопки. Чтобы он отображался полностью, рекомендуем не превышать заданное количество символов в зависимости от размещения текста: `20` символов — при 1 кнопке в ряду, `10` — при 2, `5` — при 3, `3` — при 4

          - **`url`** — string

            до `2048` символов

        - Вариант `type = "request_geo_location"` — RequestGeoLocationButton

          После нажатия на такую кнопку клиент отправляет новое сообщение с вложением текущего географического положения пользователя

          - **`text`** — string

            от `1` до `128` символов

            Видимый текст кнопки. Чтобы он отображался полностью, рекомендуем не превышать заданное количество символов в зависимости от размещения текста: `20` символов — при 1 кнопке в ряду, `10` — при 2, `5` — при 3, `3` — при 4

          - **`quick`** — boolean · optional

            По умолчанию: `false`

            Если `true`, отправляет местоположение без запроса подтверждения пользователя
            Если `false`, возвращает модальное окно с дополнительным уточнением об отправке местоположения

        - Вариант `type = "request_contact"` — RequestContactButton

          После нажатия на такую кнопку клиент отправляет новое сообщение с вложением текущего контакта пользователя

          - **`text`** — string

            от `1` до `128` символов

            Видимый текст кнопки. Чтобы он отображался полностью, рекомендуем не превышать заданное количество символов в зависимости от размещения текста: `20` символов — при 1 кнопке в ряду, `10` — при 2, `5` — при 3, `3` — при 4

        - Вариант `type = "open_app"` — OpenAppButton

          Кнопка для запуска мини-приложения

          - **`text`** — string

            от `1` до `128` символов

            Видимый текст кнопки. Чтобы он отображался полностью, рекомендуем не превышать заданное количество символов в зависимости от размещения текста: `20` символов — при 1 кнопке в ряду, `10` — при 2, `5` — при 3, `3` — при 4

          - **`web_app`** — string · optional

            Публичное имя (username) бота или ссылка на него, чьё мини-приложение надо запустить

          - **`contact_id`** — integer &lt;int64&gt; · optional

            Идентификатор бота, чьё мини-приложение надо запустить

          - **`payload`** — string · optional

            Параметр запуска, который будет передан в [initData](../../docs/webapps/bridge.md#window.WebApp.initData) мини-приложения

        - Вариант `type = "message"` — MessageButton

          Кнопка для запуска мини-приложения

          - **`text`** — string

            от `1` до `128` символов

            Текст кнопки, который будет отправлен в чат от лица пользователя

        - Вариант `type = "clipboard"` — ClipboardButton

          При нажатии на кнопку с типом `clipboard` текст, указанный в свойстве `payload`, копируется в буфер обмена

          - **`text`** — string

            от `1` до `128` символов

            Видимый текст кнопки. Чтобы он отображался полностью, рекомендуем не превышать заданное количество символов в зависимости от размещения текста: `20` символов — при 1 кнопке в ряду, `10` — при 2, `5` — при 3, `3` — при 4

          - **`payload`** — string

            до `1024` символов

            Текст, который будет скопирован

  - Вариант `type = "location"` — LocationAttachmentRequest

    Запрос на прикрепление геолокации к сообщению

    - **`latitude`** — number &lt;double&gt;

      Широта, до 15 символов

    - **`longitude`** — number &lt;double&gt;

      Долгота, до 15 символов

  - Вариант `type = "share"` — ShareAttachmentRequest

    Запрос на прикрепление предпросмотра контента по внешнему URL

    - **`payload`** — object ShareAttachmentPayload

      Данные для прикрепления предпросмотра контента по внешнему URL

      - **`url`** — string · Nullable · optional

        от `1` символа

        URL, прикреплённый к сообщению для предпросмотра медиавложения

      - **`token`** — string · Nullable · optional

        Токен вложения

- **`link`** — object NewMessageLink · Nullable

  Ссылка на сообщение в чате или пост в канале. Ссылки на комментарии к постам в каналах не поддержаны

  - **`type`** — enum MessageLinkType

    Возможные значения в enum: `"forward"` `"reply"`

    Тип связанного сообщения:
    - `"reply"` — ответ на сообщение или комментарий в чате или канале
    - `"forward"` — пересланное сообщение в чате или канале

    **Для комментариев поддерживается только тип `reply`**

  - **`mid`** — string

    ID исходного сообщения

- **`notify`** — boolean · optional

  По умолчанию: `true`

  Если `false`, участники чата не получат push-уведомления. Для каналов необходимо отправлять запрос с `notify = true` или без этого поля, т.к. каналы не подразумевают отправку постов без push-уведомлений

- **`format`** — enum TextFormat · Nullable · optional

  Возможные значения в enum: `"markdown"` `"html"`

  Разметка текста сообщения. Подробнее — в разделе [Форматирование](../index.md#Форматирование%20текста%20в%20сообщениях)

## Пример объекта

```json
{
 "text": "string",
  "attachments": [{ ... }],
  "link": { ... },
 "notify": true,
 "format": "markdown"
}
```
