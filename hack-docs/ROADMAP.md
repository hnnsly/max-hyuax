Вехи переносятся в GitHub Milestones, эпики — в Issues с лейблами `epic`, `pair-a`, `pair-b`, `devops`, `docs`. Детали сроков — [GENERAL_PLAN](GENERAL_PLAN.md); требования — [SRS](SRS.md); истории — [user-stories](requirements/user-stories.md).

## После MVP
- **Экосистема** (если не вошла в M2): H3 «Совет дома», H4 «Приём в УК», H5 модерация канала, собственный домовой чат, поддержка 60+.
- **Финал 29.10 (Казань):** сценарий пилота — Москва, один район, партнёр УК (например, ГБУ «Жилищник» района) и Мосжилинспекция; метрики пилота (время до реакции, дубли, просрочки); путь B2G-пилот → SaaS для УК; тиражирование по регионам пакетами справочников.
- **Интеграции:** ГИС ЖКХ через оператора ИС, CRM или 1С УК, ПОС.
