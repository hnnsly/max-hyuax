# ADR-009: Визуальная айдентика «Адресная табличка»

## Контекст
- Команда просит запоминающийся дизайн без шаблонных решений (градиенты, одни и те же шрифты).
- Мини-приложение живёт внутри MAX. UX и UI — 20% продуктовой оценки: интерфейс должен ощущаться родным для MAX на iOS, Android, desktop и web.
- Реальные токены MAX UI (Storybook): `system-ui`, акцент `#007AFF`, поверхности `#EDEEF2` / `#FFFFFF` (тёмные `#0F0F12` / `#17181C`), радиусы 10–20.
- Аудитория — жители панельных домов Москвы 70–90-х и сотрудники УК ([ADR-002](002-product-scope.md)); тон — гибрид строгих Госуслуг и дружелюбного соседа.
- Выбор сделан в plan mode из трёх направлений: «Адресная табличка», «Доска объявлений», «Инженерная маркировка».

## Решение
1. **Направление «Адресная табличка».** Визуальный язык взят из материального мира подъезда:
   - эмалевая табличка с номером дома и подъезда;
   - узкий гротеск для цифр;
   - штамп статуса.
2. **Нативная база MAX UI + фирменный слой.** Ячейки, списки, поля, отступы и тёмная тема остаются нативными. Фирменными становятся шрифт, один цвет (эмаль `#1B3F94`), таблички, узкие цифры и штамп.
3. **Шрифты:** Sofia Sans (интерфейс) и Sofia Sans Extra Condensed (цифры и табличные надписи), OFL, полная кириллица, self-host.
4. **Цвета состояний:** сурик `#C23A22` — просрочка и отказ; янтарь `#8A5A00` — в работе; трафаретный зелёный `#2C7548` — выполнено. Всё дублируется текстом.
5. **Единственная автоматическая анимация** — штамп при смене статуса (с хаптиком в MAX); всё уважает `prefers-reduced-motion`.
6. **Спецификация:**
   - дизайн-система — [DESIGN-SYSTEM.md](../design/DESIGN-SYSTEM.md);
   - токены — [tokens.css](../design/tokens.css);
   - кликабельный прототип — [prototype/index.html](../design/prototype/index.html), опубликован приватным артефактом.
7. **Название продукта не выбрано** — в дизайне стоит плейсхолдер `‹Название›`.

## Рассмотренные альтернативы
| Вариант | Почему не выбран |
|---|---|
| «Доска объявлений»: бумажные объявления, отрывные талоны, машинопись | запоминается, но есть риск китча и мало «строгости Госуслуг» |
| «Инженерная маркировка»: графит, трафарет, цвета по ГОСТ, штриховка | жёстко для жителей, близко к шаблону «тёмный фон + кислотный акцент» |
| Полностью своя визуальная система поверх MAX UI | риск «чужеродности» внутри MAX и потери баллов UX |
| Максимально нативно (только акцентный цвет) | безопасно, но продукт не запоминается |

## Последствия
- **Плюсы:**
  - узнаваемость (табличка работает и в приложении, и на наклейке в лифте);
  - доверие к наклейке;
  - нативное поведение;
  - одна анимация с понятным смыслом;
  - контраст проверен.
- **Минусы и риски:**
  - нужно self-host двух шрифтов (≈ +100–150 КБ woff2);
  - набор своих компонентов (Plate, Stamp, SegmentedSwitch, BottomSheet, Toast и др.);
  - фильтр неровности штампа проверить на производительность в web-клиенте;
  - название продукта нужно выбрать до финальной вёрстки наклейки.
- **Задачи:**
  - перенести `tokens.css` в `miniapp/src/theme/`;
  - компоненты из §4 DESIGN-SYSTEM в `miniapp/src/components/`;
  - шаблон сообщения бота в backend;
  - генерация наклеек A6 с QR (PDF) для демо.
