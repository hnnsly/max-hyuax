# ADR — архитектурные решения

Каждое значимое решение (архитектура, стек, данные, процесс, продуктовая граница) оформляется отдельным файлом `NNN-kebab-case.md`. Решения не переписываются: устаревшее получает статус `superseded` и ссылку на новое.
