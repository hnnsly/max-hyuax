# ADR-014: Модель и запрос для подсказки категории

## Контекст
- [ADR-008](008-llm-self-hosted.md) оставил выбор модели на Спайк 0. Подсказка реализована в части F1: `app/hints` + `storage/llm` + `POST /classify` + бот.
- Замер 24.09 на Ollama 0.34.3 (`task test:llm`, 4 фразы без ключевых слов справочника или с обманчивыми словами):

| Модель | Точность | Задержка, прогретая | Холодный старт |
|---|---|---|---|
| `qwen3:1.7b`, выбор из английских кодов | 1 из 3 | ~0,7 с | 15 с |
| `qwen3:1.7b`, выбор из русских названий | 2 из 4 | ~1–2 с | — |
| `qwen3:4b`, выбор из русских названий | 4 из 4 | ~2 с | 36 с |

## Решение
1. **Модель по умолчанию `qwen3:4b`** (Apache 2.0): около 2,5 ГБ, около 4 ГБ в памяти, работает на CPU. `qwen3:1.7b` оставлен как облегчённый вариант через `OLLAMA_MODEL`.
2. **Модель выбирает русское название категории** из `enum` в JSON-схеме `format`; к названию в запросе добавляются слова-примеры из справочника. Код находит адаптер. Дополнительно в запросе стоят `think: false` и `temperature: 0`.
3. **Устойчивость:**
   - таймаут 8 с;
   - не больше 2 параллельных запросов, остальные сразу получают `ErrBusy`;
   - при любой ошибке работают ключевые слова;
   - «other» от модели уступает ключевым словам.
4. **Прогрев.** При старте `api` модель загружается в память, повторы идут, пока `ollama-pull` не скачает модель. `keep_alive: -1` держит модель в памяти постоянно.

## Рассмотренные альтернативы
| Вариант | Почему не выбран |
|---|---|
| `qwen3:1.7b` по умолчанию | половина фраз мимо, подсказка теряет смысл |
| Коды категорий в `enum` | маленькая модель путает английские коды (`garbage` для протечки) |
| Few-shot примеры в запросе | длиннее запрос и медленнее; 4b и без них справилась на наборе |
| Модели 7B+ | на CPU VPS задержка выше таймаута |

## Последствия
- **Плюсы:** подсказка работает на фразах без ключевых слов; без модели ничего не ломается.
- **Минусы и риски:** 4 ГБ памяти на VPS; на слабом CPU подсказка может не укладываться в 8 с, тогда работают ключевые слова.
- **Задачи:** на стенде замерить задержку и при нехватке ресурсов переключить `OLLAMA_MODEL=qwen3:1.7b` или выключить профиль `llm`.

## Связанные требования
FR-LLM-01, NFR-09, SEC-12.
