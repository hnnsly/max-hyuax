# ADR-007: Сдача из отдельного чистого репозитория

## Контекст
- В истории рабочего репозитория есть `Case.md` и правила хакатона, а п. 11.3 запрещает передавать Задание третьим лицам ([risks R8](../research/risks.md)).
- В рабочем репозитории лежат внутренняя база знаний и файлы агентов, которые не сдаются ([ADR-001](001-docs-separation.md)).
- Для сдачи нужны зафиксированный commit hash и код, который после дедлайна не меняется ([Case.md](../Case.md)).
- Решение команды — отдельный чистый репозиторий ([Блок Г](../interview/BLOCK-G.md)).

## Решение
1. Рабочий репозиторий остаётся приватным.
2. Для сдачи создаётся **отдельный репозиторий** (доступ жюри по ссылке; приватный с доступом или публичный — по требованиям организаторов).
3. При code freeze скрипт экспорта (`scripts/export-submission`, создаётся на этапе 4):
   - копирует только разрешённое: `backend/`, `miniapp/`, `deploy/`, `api/`, `docs/`, `README.md`, `DATA-API.yaml`, `compose.yaml`, `.env.example`, `.dockerignore`, лицензии и файлы зависимостей;
   - **исключает:** `hack-docs/`, `CLAUDE.md`, `AGENTS.md`, `LEAN-CTX.md`, `.claude/`, `.obsidian/`, `.env`, любые локальные артефакты;
   - запускает проверки: поиск ИИ-меток (`Co-Authored-By: Claude`, `Generated with`, `Claude`, `Gemini`, `ChatGPT`, `generated by` — по коду, `docs/` и сообщению коммита), поиск секретов (gitleaks или аналог), сборку `docker compose build` с замером времени.
4. В чистом репозитории — **один коммит** (или короткая осмысленная история без ИИ-трейлеров); его hash идёт на первый слайд.
5. После дедлайна чистый репозиторий не меняется.

## Рассмотренные альтернативы
| Вариант | Почему не выбран |
|---|---|
| Orphan-ветка в рабочем репозитории | риск открыть доступ к `main` с историей |
| Архив + контрольная сумма | допустимо, но ссылка на репозиторий удобнее проверяющим |
| Переписать историю рабочего репозитория | рискованно и не нужно |

## Последствия
- **Плюсы:** закрыты риски п. 11.3 и п. 9.5; чистая презентация кода.
- **Минусы:** нужен скрипт и репетиция экспорта заранее (не в последний день).
- **Задачи:** скрипт экспорта и репетиция к 27.09; финальный экспорт 29.09.
