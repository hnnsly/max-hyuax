# ADR-016: Геокодер и лицензии открытых данных

## Контекст
Часть 6 [GEN_V2_PLAN](../GEN_V2_PLAN.md): УК или район загружают реестр домов из CSV, а у части домов нет координат. «Найти дома рядом» показывает дома, но не адрес, где стоит житель. Нужен геокодер на открытых данных. Правило команды: никаких лицензий, которые требуют открыть наш код.

## Решение
- **API, совместимое с Nominatim**, по HTTP. Адрес задаёт `GEOCODER_URL`, пусто — геокодер выключен, всё работает без него.
  - Для демо — публичный `nominatim.openstreetmap.org`, для пилота — свой экземпляр Nominatim или совместимый сервис.
  - Прямой запрос: `Москва, <адрес>`. Принимается только результат уровня дома: `place_rank >= 30` и есть `house_number`. Иначе считаем, что адрес не найден: координаты улицы вместо дома хуже, чем пустые.
  - Обратный запрос: `road` и `house_number` → «Ореховый бульвар, 15».
- **Лицензии:**
  - код Nominatim — GPL-2.0, но мы его не включаем и не меняем, только вызываем по сети. Копилефт на наш код не переходит;
  - данные OpenStreetMap — ODbL 1.0. Условие — атрибуция: подпись «© участники OpenStreetMap» рядом с найденным адресом в мини-приложении, в README и `docs/`. Координаты импортированных домов — производная база данных; при публикации её тоже нужно атрибутировать, внутри сервиса это выполнено;
  - порт `app.Geocoder` скрывает поставщика: заменить на другой геокодер можно без правок сценариев.
- **Правила публичного сервера** (Nominatim Usage Policy):
  - не больше 1 запроса в секунду: адаптер держит паузу между запросами;
  - User-Agent с названием приложения и контактом (`GEOCODER_USER_AGENT`);
  - кэш результатов в памяти, обратный запрос по координатам с округлением до 4 знаков (около 10 м);
  - массовое геокодирование запрещено: импорт большого реестра делать на своём Nominatim.
- **Импорт** (`api import-houses`): CSV `id,address,district,org_id,year,floors,entrances,lat,lon,source`. Дом с подъездами и объектами с QR-кодами создаётся или обновляется по `id`, без `id` он строится из адреса. Ошибки строк не останавливают импорт, отчёт с номерами строк.

## Рассмотренные альтернативы
| Вариант | Почему не выбран |
|---|---|
| Яндекс или 2ГИС геокодер | Коммерческие условия, ключи, запрет хранить результаты |
| Photon (Apache-2.0) | Другой формат API; можно подключить позже за тем же портом |
| DaData | Платно для этого объёма, ключ |
| Без геокодера | Импорт без координат ломает «Найти дома рядом» |

## Последствия
- **Плюсы:** без ключей и договоров; лицензии не требуют открывать код.
- **Минусы и риски:**
  - публичный Nominatim плохо знает московские корпуса («17к2» находит только улицу), такие дома импортируются без координат, это видно в отчёте;
  - ответ публичного сервера медленный и не гарантирован: API ждёт обратный адрес не дольше 3 с, иначе отвечает без адреса.
- **Задачи:** для пилота поднять свой Nominatim с выгрузкой OSM по Москве.

## Связанные требования
FR поиска дома, масштабирование на район (критерии оценки), ADR-017.
