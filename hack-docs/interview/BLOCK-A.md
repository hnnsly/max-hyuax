## А. Продуктовый фокус и целевая аудитория

| № | Вопрос | Ответ |
|---|---|---|
| А1 | Узкая механика или экосистема | **H1 + H2 + шеринг из H5**, «но думаю успеем и экосистему сделать» |
| А2 | Первичный пользователь | **Житель МКД под управлением УК** |
| А2b | Тип дома | **Сначала самый массовый фонд — панель 70–90-х**, далее масштабируем |
| А3 | Кто закрывает заявку в демо | **Роль «УК» в мини-приложении** |
| А4 | Позиционирование к «Госуслуги.Дом» | **Сначала надстройка**; если в ходе исследования выясним, что можем полноценно и лучше госбота, — сделаем |
| А5 | Доступ к реальным людям для валидации | **Не тратим на это время**: отвечаем аргументированными допущениями |
| А6 | Пилотный контекст | **Город команды — Москва** |
| А7 | Главная метрика | **Все предложенные**: время до реакции УК, дубли на проблему, доля просрочек; конверсия менее значима |
| А8 | Эскалация в ГЖИ | **Should: PDF + инструкция** |
| А9 | LLM в продукте | **Классификация + черновик обращения** |
| А10 | Что соседи видят о присоединившихся | **Только счётчик** |
| А11 | Сбор позиций собственников | **Опрос без юридической силы (Could)** |
| А12 | Массовые уведомления | **Только участникам заявок** |
| А13 | Аудитория 60+ | **Предварительно не приоритет MVP**, возможно сделаем по ходу |
| А14 | Модель внедрения | **Гибрид: B2G-пилот → SaaS** |
| А15 | Won't Have | **Оплата и показания; верификация собственности** |
| А16 | Вау-момент | **QR в лифте → заявка за 3 шага** |
| А16b | Тон | **Гибрид строгих Госуслуг и дружелюбного соседа** |
