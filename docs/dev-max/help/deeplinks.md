# Диплинки

## Что такое диплинки в MAX?

Диплинки (deep links) — это специальные ссылки, которые позволяют открывать чат-ботов или мини-приложения MAX с передачей дополнительных параметров. С их помощью можно передавать контекстную информацию, отслеживать источники переходов или автоматически выполнять определённые действия при запуске

## Какие версии клиентов MAX поддерживают диплинки?

Механизм диплинков поддерживается в следующих версиях клиентов MAX:

- **iOS:** версия 2.7.0 и выше
- **Android:** версия 2.9.0 и выше

## Как создать диплинк для чат-ботов?

Используйте следующий формат ссылки:

```
https://max.ru/<botName>?start=<payload>
```

Где:

- `<botName>` — никнейм бота
- `<payload>` — дополнительные данные (до 128 символов)

Подробнее о диплинках ботов читайте в [разделе «Разработка сценариев: с кодом → API»](../docs/chatbots/bots-coding/prepare.md#Работа%20с%20диплинками)

Примеры использования диплинков для запуска ботов смотрите в [разделе «Запуск бота через диплинк из внешнего приложения»](../docs/chatbots/bots-coding/prepare.md#Запуск%20бота%20через%20диплинк%20из%20внешнего%20приложения)

## Как создать диплинк для мини-приложения?

Используйте следующий формат ссылки:

```
https://max.ru/<botName>?startapp=<payload>
```

Где:

- `<botName>` — имя бота, к которому привязано мини-приложение
- `<payload>` — необязательный параметр с дополнительными данными (до 512 символов)

Подробнее о диплинках приложений читайте в [разделе «Подключение мини-приложения»](../docs/webapps/introduction.md#Работа%20с%20диплинками)

Примеры использования диплинков для запуска мини-приложений смотрите в [разделе «Запуск мини-приложения через диплинк из внешнего приложения»](../docs/webapps/introduction.md#Запуск%20мини-приложения%20через%20диплинк%20из%20внешнего%20приложения)

## Как создать диплинк для шеринга текста?

Используйте следующий формат ссылки:

```
https://max.ru/:share?text=<текст сообщения>
```

Где:

- `text` — текст, который пользователь отправит в выбранный чат или канал

Диплинк `:share` открывает экран «Отправить в MAX» и подставляет переданный текст в поле сообщения. Применяйте URL encoding для параметра `text`, если текст содержит пробелы, спецсимволы или эмодзи

Подробнее о диплинке `:share` читайте в [разделе «Подключение мини-приложения»](../docs/webapps/introduction.md#Диплинк%20для%20шеринга%20контента)
