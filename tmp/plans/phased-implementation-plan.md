## 1. Архитектура и интеграция с OpenStreetMap (ASCII)

### 1.1 Схема геокодера на базе OpenStreetMap (Photon API + Go Proxy Cache)

```
+-----------------------------------------------------------------------------------+
|                                  КЛИЕНТЫ MAX                                      |
|                                                                                   |
|   +------------------------------------+    +---------------------------------+   |
|   |         Чат-бот в MAX              |    |      Мини-приложение (Web)      |   |
|   |  - Поиск по GPS (кнопка в боте)    |    |  - SearchInput (Автокомплит)    |   |
|   |  - Быстрый выбор из подсказок      |    |  - Интерактивная карта OSM      |   |
|   |  - Живые карточки со статусом      |    |    (Leaflet + OSM tiles)        |   |
|   +-----------------+------------------+    +----------------+----------------+   |
+---------------------|----------------------------------------|--------------------+
                      | Webhook (HTTPS:443)                    | REST API /api/v1
                      v                                        v
+-----------------------------------------------------------------------------------+
|                             BACKEND (Go + Fiber v3)                               |
|                                                                                   |
|  +-----------------------------------------------------------------------------+  |
|  |                            ADAPTER: Geo & Maps                              |  |
|  |   [GET /api/v1/geo/suggest?q=...]       [GET /api/v1/geo/reverse?lat=&lon=] |  |
|  |   - In-Memory LRU Cache (быстрый повтор) - Ограничение bbox Москвы          |  |
|  +-----------------------------------+-----------------------------------------+  |
|                                      |                                            |
|                  +-------------------+-------------------+                        |
|                  | (Запрос во внешнюю сеть)              | (Локальная привязка)   |
|                  v                                       v                        |
|   +------------------------------+       +------------------------------------+   |
|   | OpenStreetMap / Photon API   |       | PostgreSQL 16 (реестр домов и УК)  |   |
|   | (открытый OSM геокодер)      |       | - Привязка координат OSM к дому    |   |
|   | - https://photon.komoot.io   |       | - Определение обслуживающей УК     |   |
|   | - поиск по улицам и домам РФ |       | - Fallback при отсутствии сети     |   |
|   +------------------------------+       +------------------------------------+   |
+-----------------------------------------------------------------------------------+
```

### 1.2 Как работает поток автокомплита через OpenStreetMap:
1. Житель вводит адрес в мини-приложении: `"лескова 12"`.
2. Компонент `SearchInput` с дебаунсом (300 мс) отправляет запрос на наш бэкенд: `GET /api/v1/geo/suggest?q=лескова+12`.
3. Бэкенд Go проверяет локальный кэш, а при промахе запрашивает OpenStreetMap через открытый API Photon (`bbox` Москвы: `37.3,55.5,37.9,56.0`, язык `ru`).
4. Результаты OSM дополняются данными из нашей БД (название управляющей компании, контакты диспетчерской АДС).
5. Пользователь видит выпадающий список: выбирает нужный дом → мини-приложение отображает мини-карту на тайлах OpenStreetMap с меткой дома.

## 4. Критерии приемки (Definition of Done)
1. **Тесты:** `go test ./...` проходит успешно.
2. **Контракт:** Эндпоинты соответствуют `api/openapi.yaml`.
3. **Геосервис:** Автокомплит адресов OpenStreetMap работает быстро (<100 мс с кэшем), есть fallback.
4. **UX-состояния:** 4 состояния экрана (загрузка, успех, ошибка, пустой список).
5. **Кроссплатформенность:** Работает в Mobile и Web клиентах MAX.
6. **Безопасность:** Нет секретов в коде, EXIF удален, ПДн защищены.
7. **Документация:** Синхронизирована в `docs/`.
